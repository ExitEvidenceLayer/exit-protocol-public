# Product access and support

Start at [exit-protocol.io](https://exit-protocol.io). Public recorded cases require
no wallet connection or token purchase. Read [PRODUCT.md](PRODUCT.md) before treating
the research desk as a general live query service.

**Project business contact:** [contact@exit-protocol.io](mailto:contact@exit-protocol.io).
Describe your research or integration use case, network, required time range and
desired output without including confidential data. An enquiry is not an order,
credential request approval or promised response deadline.

Public GitHub issues are suitable for documentation corrections and reproducible
public website problems. This repository does not operate a public research queue,
customer ticket SLA or vulnerability bounty.

For security concerns, follow [SECURITY.md](SECURITY.md). Keep keys, personal
identifiers and private investigations out of issues, screenshots and attachments.
